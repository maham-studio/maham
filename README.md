# مهام — نظام إدارة مهام الاستوديو

نظام إدارة مهام عربي (RTL) لفريق إنتاج إعلامي: مصورون، مونتير، ومساعدون. PWA قابل للتثبيت على الهاتف ويعمل من المتصفح.

## التشغيل محليًا

```bash
./start.sh
```

أو يدويًا:

```bash
npm install
npx prisma db push   # إنشاء قاعدة البيانات SQLite
node prisma/seed.js  # بيانات تجريبية (تُتخطى إن وُجدت بيانات)
npm run build && npm start
```

ثم افتح http://localhost:3000

للتطوير بدل البناء: `npm run dev`

## أدوار وصلاحيات

الأدوار تُدار من شاشة «الأدوار» (إضافة دور جديد وصلاحياته بدون كود). الصلاحيات المتاحة:
عرض كل المهام، مراجعة واعتماد المهام، إدارة المشاريع، إدارة القوالب، إدارة المستخدمين، إدارة الأدوار.
